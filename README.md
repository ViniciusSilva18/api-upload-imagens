# 🖼️ API Upload & Otimização de Imagens

**Upload de imagens com conversão automática para WebP, redimensionamento e compressão.**

[![Node.js](https://img.shields.io/badge/Node.js-339933?style=for-the-badge&logo=nodedotjs&logoColor=white)]()
[![Sharp](https://img.shields.io/badge/Sharp-Image_Processing-99cc00?style=for-the-badge)]()

</div>

## ✨ Funcionalidades
- 📤 Upload single e múltiplo (até 10 imagens)
- ⚡ Conversão automática para WebP
- 📐 Redimensionamento inteligente (máx. 1920px)
- 📊 Estatísticas de compressão (ex: "68% menor")
- 🛡️ Validação de tipo e tamanho (máx. 10MB)

## 🛠️ Setup
```bash
npm install && npm run dev
# POST /upload com multipart/form-data (campo: "image")
```
